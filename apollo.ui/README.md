# آپولو — رابط کاربری (apollo.ui)

رابط کاربری پلتفرم آپولو؛ ساخته‌شده با React، TypeScript، Vite، Tailwind CSS v4 و shadcn/ui.
پروژه به‌صورت کامل فارسی، راست‌چین (RTL) و فقط در حالت تاریک طراحی شده است.

## راه‌اندازی

```bash
npm install
npm run dev
```

پس از اجرا، برنامه روی [http://localhost:5173](http://localhost:5173) در دسترس است.

## دستورهای موجود

| دستور               | توضیح                                        |
| ------------------- | -------------------------------------------- |
| `npm run dev`       | اجرای سرور توسعه با بارگذاری داغ             |
| `npm run build`     | بررسی نوع‌ها و ساخت نسخه تولید در `dist/`    |
| `npm run preview`   | پیش‌نمایش خروجی تولید                        |
| `npm run lint`      | اجرای ESLint روی کل پروژه                    |
| `npm run typecheck` | بررسی نوع‌ها بدون تولید خروجی                |
| `npm run format`    | قالب‌بندی کد با Prettier                     |

## ساختار پوشه‌ها

ساختار پروژه بر پایه «تفکیک بر اساس قابلیت» (Feature-based) چیده شده است:

```
src/
├── app/                    لایه راه‌اندازی برنامه
│   └── app.tsx             ریشه برنامه
├── assets/                 فایل‌های ایستا (لوگو و فونت وزیر)
├── components/
│   ├── shared/             کامپوننت‌های مشترک بین قابلیت‌ها
│   └── ui/                 کامپوننت‌های پایه shadcn/ui
├── features/
│   └── landing/            قابلیت صفحه فرود
│       ├── components/     کامپوننت‌های اختصاصی هر سکشن
│       ├── data/           محتوای صفحه، جدا از لایه نمایش
│       ├── landing-page.tsx
│       └── index.ts        نقطه ورود عمومی قابلیت
├── lib/                    توابع کمکی
├── index.css               توکن‌های طراحی، فونت و لایه پایه
└── main.tsx                نقطه شروع برنامه
```

قواعدی که در این ساختار رعایت می‌شود:

- هر قابلیت فقط از طریق `index.ts` خود در دسترس بیرون قرار می‌گیرد.
- محتوای متنی و داده‌ها در پوشه `data` نگهداری می‌شوند تا کامپوننت‌ها فقط مسئول نمایش باشند.
- کامپوننت‌ها کوچک و تک‌مسئولیتی هستند؛ هر سکشن صفحه یک فایل جداگانه دارد.
- نام فایل‌ها `kebab-case` و نام کامپوننت‌ها `PascalCase` است.

## سیستم طراحی

- **رنگ اصلی:** `#3c5cff` که به‌صورت توکن `--primary` در `src/index.css` تعریف شده است.
- **شعاع گوشه‌ها:** حداکثر `4px` در کل پروژه (`--radius: 4px`).
- **فونت:** وزیر (نسخه FD با ارقام فارسی) که به‌صورت محلی از `src/assets/fonts` بارگذاری می‌شود.
- **رنگ‌ها:** همه رنگ‌ها از توکن‌های معنایی (`bg-background`، `text-muted-foreground` و ...) استفاده می‌کنند؛ رنگ خام در کامپوننت‌ها نوشته نمی‌شود.
- **تم:** فقط حالت تاریک؛ توکن‌های رنگ مستقیماً در `:root` تعریف شده‌اند.

## افزودن کامپوننت جدید از shadcn/ui

```bash
npx shadcn@latest add <component-name>
```

پیکربندی پروژه در `components.json` قرار دارد و گزینه `rtl` در آن فعال است.
